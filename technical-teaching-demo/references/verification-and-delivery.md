# 验收与交付

交付前使用本清单，将实际适用项写入验证记录：检查对象、方法、结果、证据位置、未验证范围。小任务可合并记录；不要把不适用项变成新增功能。

## 分层检查

| 层次 | 通过依据 | 证明不了什么 |
| --- | --- | --- |
| 资料覆盖 | 关键材料有定位、解释入口，无失效引用 | 解释充分或语义正确 |
| 数值与逻辑 | 已知输入、中间量、预期输出及边界通过 | 原作者实验有效 |
| 交互 | 实际操作后状态和结果正确 | 学习者已理解 |
| 视觉与可访问性 | 检查桌面/窄屏截图、键盘路径和焦点 | 所有浏览器均兼容 |
| 访问与恢复 | 文件、HTTP、解压包及服务重启实际可用 | 用户前台浏览器已显示 |
| 技术语义 | 对照来源审查假设、机制、推导与结论 | 学习者已经掌握 |
| 学习效果 | 学习者独立完成闭卷或迁移任务 | 所有学习者都会达到同样效果 |

## 交互与视觉检查

- 控件要检查数值和结果，不能只证明可点击。滑块有当前值；重置恢复初始状态；答案展开/收起不改变掌握状态。
- 存在搜索弹窗时检查关闭后状态与焦点；存在笔记时实际输入、保存、刷新恢复和导出，检查存储失败提示。没有这些功能时无需添加。
- 导航点击后等待目标章节或锚点状态稳定再断言，不用任意延时掩盖时序问题。
- 检查桌面和窄屏的长路径、表格、公式、SVG。局部滚动、断行优于压小全部文字；检查键盘操作、焦点可见、跳过导航和控件标签。
- 捕获控制台异常、失败资源及意外网络请求。下载触发 `net::ERR_ABORTED` 时先验证实际文件和内容，仅排除已确认的下载事件，不能忽略全部取消请求。

## 本地 HTML 的实际使用路径

- [ ] 确认交付目录、HTML 和配套相对资源存在；公开包没有私人资料或无权分发的素材。
- [ ] 断网打开文件模式，核对正文、公式、关键交互。若功能必须使用 HTTP，明确限制并验证备用阅读方式。
- [ ] 提供只监听 `127.0.0.1`、仅服务交付目录的启动入口。不为预览暴露整个工作区或用户目录。
- [ ] 检查 HTTP 状态、资源、实际 DOM 和关键操作。HTTP 200 只说明请求成功。
- [ ] 停止服务，再使用交付命令恢复；处理端口占用，给出可执行替代。说明服务需持续运行，电脑重启后要重新启动。
- [ ] ZIP 做 CRC、文件内容一致性及解压后的文件/HTTP 检查。入口依赖执行权限时核对权限；用 `python3 serve.py` 启动则不要求可执行位。
- [ ] 提供可复制的本机地址、停止和重启方式、离线入口、已验证浏览器与未验证项。

应用内预览、打开请求被接受、HTTP 200、无头浏览器渲染和用户实际显示是不同证据。只记录检查到的层次；GUI 操作遵守当前会话授权，不能因为需要验收就自行获取屏幕。

同样的“打不开”可能发生在文件链接、服务、资源或客户端。读取当前证据，不沿用另一个项目的根因。修复入口不等于查明原链接失败原因。

若使用本地存储，说明 file、HTTP、端口和浏览器变化可能造成数据隔离；迁移前提供导出方式。最小模板不保存笔记或进度，无需引入存储系统。

## 呈现层检查（做过视觉改造时）

- [ ] 升级层只新增样式与脚本，课程内容、数据与交互逻辑与改造前一致；删除两个文件与两行引用能完全还原。
- [ ] 字体按主题选定且为本地字体栈，无网络字体请求；`document.fonts.check()` 仅辅助检查加载状态，实际命中需查看渲染字体，未检查时明确记录为未验证。
- [ ] 首屏只有一个显示级焦点；主标题在任何宽度都不超过两行。
- [ ] 图表只画材料里已有的数字，数轴按真实比例，图注标明来源与"是否本机复现"；标签不互相压盖。
- [ ] 门控通过后仍回看 1440 / 768 / 390 三档截图：焦点唯一、无叠字或遮挡、无竖排或折行按钮、色调场边缘干净。
- [ ] 未用脚本重排 DOM 做排序或布局；窄屏无横向溢出。
- [ ] 课程自带测试在改动后重跑，并保留输出；未跑的部分写进未验证范围。

## 最终记录

写明实际产物、启动命令、地址、离线包，以及通过/失败/未验证项。不能把前端检查称为模型训练或 benchmark 复现，也不能把用户接受交付升级成掌握或科研终审通过。缺少独立语义审校时保留该限制，不虚构审校人或验收结果。
