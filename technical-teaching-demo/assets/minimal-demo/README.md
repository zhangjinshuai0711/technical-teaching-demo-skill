# 最小教学页面

这是原创的加权评分教学示例，不含论文、项目数据、笔记或学习进度保存。

## 打开与恢复

直接在浏览器打开同目录 `index.html`，可断网阅读和操作。

需要 HTTP 入口时，在本目录执行（Python 3.9+）：

```sh
python3 serve.py
```

复制终端输出的 `http://127.0.0.1:8765/` 到浏览器。保持进程运行；按 Ctrl+C 停止，重新运行相同命令即可恢复，电脑重启后也需重启服务。端口被占用时运行 `python3 serve.py --port 8766`，或使用 `--port 0` 自动分配并复制实际输出地址。无需给脚本设置执行权限。

启动器不会自动打开或读取浏览器，只服务本目录，拒绝指向目录外的符号链接，不提供目录列表。仅用于本机预览。无需 Node.js、构建工具或联网资源。

## 改成你的教学内容

1. 复制整个目录，保持文件的相对位置；不要直接修改安装的 skill 作为课程项目。
2. 在 `index.html` 中替换目标、正文、手算、自测、来源与简化边界；章节 ID 与目录链接保持一致。
3. 在 `demo.js` 中替换计算和对应 DOM 更新。先用已知输入与边界核算，再连接控件。
4. 按需要调整 `style.css`，复验窄屏与键盘。没有持续价值的功能不添加。

公式为普通文字，因此不需要联网数学渲染器。复杂公式如引入渲染库，应确认许可并随包提供所需资源，重新验证离线行为。

## 检查

初始 A=80、B=50、w=0.60，结果应为 68.0；w=0 时为 B，w=1 时为 A。用 Tab 和方向键操作滑块；Enter 操作重置按钮及答案；检查重置、目录折叠和窄屏无整页溢出。

本示例不存储数据。后续添加笔记/进度时需说明 file、HTTP、端口及浏览器的存储差异，并提供导出和存储失败提示。

打包时包含本目录全部文件，完整解压后打开或启动。验收需分别记录文件模式、HTTP、服务重启和解压包；HTTP 200 不代表用户浏览器已显示或课程语义已通过审校。
