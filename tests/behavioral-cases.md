## A：论文机制精读

请求：我了解四则运算和向量，想通过一个小 HTML 理解以下片段中的机制，并能手算一次输出；保留来源和简化边界，不需要完整网站。

材料：合成论文 v1，第 2 节，式 (1)：x1=2、x2=8，节点 1 的邻居集合只有节点 2，r1=λx1+(1−λ)mean(neighbors)，示例 λ=0.25。算子混合自身与邻居信息，没有训练或实验评估记录。

核查：来源应标合成；初始 r1=6.5；改变 λ 时结果正确；不声称进行训练或复现实验。

## B：非论文算法教学

请求：我会简单 JavaScript，需要二分查找交互 HTML。对 [2,5,8,12,16,23] 寻找 12，能改目标，显示区间与比较过程，说明找不到；不要账户、笔记或搜索。

材料：闭区间 [left,right]，mid=floor((left+right)/2)，相等返回 mid，小于目标则 left=mid+1，否则 right=mid−1，left>right 返回 −1。数组无重复，输入为有限整数。

核查：12 的结果是零基索引 3；2 与 23 可命中边界；不存在的 7 返回 −1；0 仍是合法目标；无效输入应有反馈；不要照搬加权评分。

## C：源码分支讲解

请求：用一个开关和中间量说明当前配置的真实行为及关闭后的区别；输入 a=4、b=2，不需要真实训练。

```python
config = {"dynamic": True, "static_weight": 0.9}
def combine(a, b, config):
    weight = config["static_weight"]
    if config["dynamic"]:
        weight = a / (a + b)
    return weight * a + (1 - weight) * b
```

核查：开启时有效权重为 2/3、输出为 10/3；关闭时权重为 0.9、输出为 3.8。静态变量存在不代表当前生效。页面应明确输入范围。
